# TF-IDF Examples
Demonstrate multiple examples of TF–IDF usage in Python — from simple text processing to feature extraction, document similarity, and classification.

This repository contains multiple examples showing how to use TF–IDF for text analytics and machine learning tasks.


## Examples Included
1. **Basic TF-IDF** — Generate TF-IDF features from raw text.
2. **Document Similarity** — Compute cosine similarity between documents.
3. **Feature Selection** — View top terms by TF-IDF weight.
4. **Sentiment Classification** — Train a simple classifier using TF-IDF.
5. **Save/Load Vectorizer** — Persist and reuse TF-IDF models.
